# Adaptive Binarizer

Скрипт для адаптивной бинаризации изображений (в основном текстовых документов) с оценкой качества распознавания текста с помощью Tesseract OCR и метрик похожести строк.

## Технологии

- Python 3
- OpenCV (обработка изображений)
- NumPy
- Tesseract OCR (`pytesseract`)
- fuzzywuzzy (оценка качества распознавания по Levenshtein distance)

## Идея

Задача — улучшить читаемость текста на изображении перед распознаванием (OCR):

- локально подстраивать порог бинаризации под освещённость/фон
- сравнивать качество распознавания для разных вариантов бинаризации
- измерять качество через строковое сходство распознанного текста с эталонным.

Алгоритм:

1. Предобработка:
   - гамма‑коррекция,
   - медианный фильтр и инверсия (получаем «негатив» текста).
2. Блочная обработка:
   - изображение разбивается на блоки размера `block_size`,
   - в каждом блоке считается медиана и применяется адаптивный порог (`_adaptive_median_threshold`),
   - дополнительно используется Otsu‑бинаризация внутри блока и сигмоида для более мягкого разделения текста и фона.
3. Постобработка:
   - морфологическая фильтрация (удаление шума).
4. Оценка:
   - бинаризованное изображение подаётся в Tesseract,
   - результат сравнивается с эталонным текстом по `fuzzywuzzy.fuzz.ratio`.
